# TFT-LCD 面板厂多产品多站点生产排程

## 业务背景

我们这边是 TFT-LCD 面板厂，现在手上有一份现场快照，想请你把接下来这九天的生产排程排出来：快照里在制的每一个 Lot（正在机台上跑着的那些不用动、机台也别改），接下来每走一道站用哪台机台、几点 Track In、几点 Track Out，都要排到位；头三天要投的新料也一并排进去，这批料是计划定死的，必须按它标的那一天投下去，一个 Lot 都不能少。我们最看重的是出货能不能按目标交出来，其中标了出货优先级的那几支尤其要保住；站与站之间的等待有 Q-time 上限，等太久会影响品质，尽量少超。另外有几台机台这九天里得各停一次做保养，保养多长时间表里给了，具体安排在什么时候你们自己看着定，保养期间那台机台不能生产，你排的保养时间窗也要一并标上。

## 数据说明

- **排程起点是 2018-05-01 07:30，考核期到 05-10 00:00 为止**，中间这九天工厂 7×24 连续生产，不分班次、不休假。看的是 05-01 至 05-09 每天每支产品交出多少片 Glass。
- **站点串成 Flow 的顺序是按站点编号从小到大**，`Flow & Tact Time` 表的行序不是工艺顺序。
- **新投料的 Date 只精确到日，当天 07:30 起才可投**，与现场快照的时点对齐，不是当日 00:00。
- **在制 Lot 的机台号跨表写法不同**：`WIP Detail` 通常带工厂前缀 TA，`Equipment` 表不带，跨表关联时视为同一机台。`EQ_013` 没有对应的去前缀设备，只承载快照里当前正在加工的 Lot，不接其他任务。

## 评估概要

**硬约束**（任意一条踩线不是丢掉那一条记录，而是整份方案归零）：

- **加工时长必须精确等于 `FDT×60 + TT×(片数−1)` 秒**，多一秒少一秒都不合格，不能取整或自行增加缓冲。
- **站点序列必须从该 Lot 当前所在站开始、按 Flow 顺序连续推进**，不许跳站、逆序，同一站也不许出现两条记录；下一站的 Track In 不得早于上一站的 Track Out。反过来，**九天排不完可以只排到中途**，少排几站不算违规。
- **快照中的每个在制 Lot 都必须纳入排程**，至少从当前站开始给出一条加工记录；所有加工必须在 05-10 00:00 前结束。
- **在制 RUN 状态的 Lot 当前那一站不能动**：Track In 必须正好是 2018-05-01 07:30:00（精确相等，差一秒就算违规），机台也得还是原来那台。
- **同机台上相邻两个 Lot 的 Track In 间隔** ≥ 前一个 Lot 的 `TT×片数 + 切换时间`，从**前一个的 Track In** 起算，不是从 Track Out 起算。
- **机台禁限生产必须遵守**：每个站点和产品只能使用表中允许的机台；在制 RUN Lot 当前站的既有机台不受这项限制。
- **三天的新投料一个 Lot 都不能少**：每个新 Lot 都必须排进首站，且首站 Track In 不早于它标定那天的 07:30。
- **要保养的机台窗口一台都不能漏**：时长精确等于表里规定的值，整个窗口落在 05-01 07:30 到 05-10 00:00 之内，窗口内那台机台不能有任何加工记录，重叠一秒都算违规。漏给一台就整份判零。
- 所有 Track In 不得早于 05-01 07:30，Track Out 必须晚于 Track In 且不晚于 05-10 00:00；Lot、站点和机台都必须真实有效，派工序列不能为空。

**质量评分**：最看重标有出货优先级的产品按日达成，其次是全部产品的按日达成，最后才看 Q-time 超限情况。

## 注意事项

- **产出的计入时点是静置结束、不是 Track Out**。Lot 在最后一站 Track Out 后还要完成末站 Hold Time，产出按静置结束所在日期计入；晚于排程期末的不计产出。
- **达成率按「产品 × 日期」逐格计算并对当天目标封顶**，某日超出目标的产量不能转移到其他日期抵扣缺口。
- **Q-time 超限不会让方案作废**，只影响质量成绩。站间等待按上一站 Track Out 到下一站 Track In 计算；快照中处于等待状态的 Lot 还要加上已经等待的时长。
- **机台按流水式占用**：相邻 Lot 的 Track In 间隔以 `TT×前一 Lot 片数` 为基础，而不是等到前一 Lot Track Out。
- **切换时间分为换站、同站换产品、同站同产品换版本三种情形**，按机台组取表中对应值，并加在相邻 Lot 的 Track In 间隔上。
