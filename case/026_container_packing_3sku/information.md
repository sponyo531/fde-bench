# 三 SKU 单集装箱装箱优化

## 业务背景

这批货有三类 SKU 要装进同一个集装箱：ITEM_A、ITEM_B 是必装的，数量按清单上标的来；ITEM_C 没有数量要求、是推荐货，柜里剩下的空间尽量多装它。货物都立着放：高度方向必须是它原本的高度，长和宽两个方向可以互换。请给一份逐件的装箱方案：每件货在柜子里的位置和占的尺寸都标清楚。

## 产物形式

方案交一份 JSON 文件。

## 评估概要

**硬约束**（任一条踩线，整份方案判不合格）：

- **逐件一条记录，装了多少件就写多少条**；每条记录都要有货号和完整的几何字段（位置坐标加占位的长宽高），并且货号只能是清单上那三个之一，出现别的名字就算违规。
- **必装件数一件不差**：ITEM_A、ITEM_B 各自的件数必须正好等于清单上填的数字，多一件少一件都不行。ITEM_C 没有件数要求，装多少都合法。
- **立放**：每件货高度方向占的尺寸必须精确等于它自己原本的高度，不能侧放倒放。
- **只能绕竖轴转 90 度**：水平面上占的那两个尺寸，必须精确等于这个 SKU 的（长, 宽）或者对调后的（宽, 长），不能缩放、不能取整凑数。
- **尺寸按清单原值使用**：ITEM_A 与 ITEM_B 即使水平尺寸只差几毫米，也仍是两个不同规格，不能取整或四舍五入后混用。
- **不越界**：三个坐标都不能为负，且坐标加占位尺寸不超过柜内的长、宽、高。
- **不重叠**：任意两件货的三维空间不能相交；表面、棱或角刚好接触允许，只有三个方向都有正长度交叠时才算重叠。
- **不超载**：按各 SKU 的单件重量累加，全柜总重不超过最大载重。

**质量评分**：只看推荐货 ITEM_C 最终装进去多少件，越多越好。
