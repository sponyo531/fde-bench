# 车身 CFD Cd 预测

## 业务背景

车身风阻系数（Cd）预测建模任务。给你一批车的 CFD 表面网格仿真结果，一部分车公开了真实 Cd 作训练标签，请训练一个机器学习模型，预测剩余车的 Cd。不同车的 Cd 大小有差别，我们对误差怎么折算有固定口径；预测结果本身也得落在物理上可信的范围内。预测 Cd 与真值的误差，越小越好。

## 产物形式

结果交一份 CSV 表格。

## 评估概要

**硬约束**：预测 Cd 必须落在 0.05 到 1.5 的物理合理区间内。

**质量评分**：只看预测出来的 Cd 与真值贴得有多近，没有别的考量。

## 注意事项

- **贴不贴得近是按相对偏差看的**：每辆车的预测值与真值之差先除以这辆车自己的真实 Cd，再对全部待测车取算术平均，不是看绝对偏差，也不是先平方再开方。
- **0.05 到 1.5 是风阻系数的物理合理区间**，越界表示结果不可信。
