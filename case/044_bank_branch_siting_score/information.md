# 银行网点选址评分预测

## 业务背景

我们行想做一套网点选址评分，现有网点的选址评分已经算好了，分越高说明这个位置越值。拿这批数据学出评分跟网点特征的关系，把还没给分的那批点位的选址评分预测出来，新点的分数要沿用现有评分尺度，越准越好；个别大偏差和整体平均偏差怎么取舍，我们也有定规。

## 产物形式

结果交一份 CSV 表格。

## 数据说明

- **周边设施与人群画像那一大批指标是外采买来的，只覆盖了不到四成网点**，其余网点这些列整片为空。**空表示这批数据没采到，不表示周边真没有这些设施**，别按 0 理解。
- **有两三个指标不属于外采那批，是我们自己台账里的，全网点都有值**：`常住人口-35至54岁中年人群占比` 和 `周边所有银行网点总数` 在 500m / 1km / 3km 三个半径上都全覆盖；`工作人口-35至54岁中年职场骨干占比` 在 1km 和 3km 上全覆盖，但 500m 半径上仍然只有外采那批网点有值。
- **在有外采覆盖的网点里，某个「周边…数量」指标为空，表示该半径内确实没有这类设施，应按 0 理解**。这类计数指标只要采到了就至少是 1，唯独 `周边本行网点数量` 和 `周边所有银行网点总数` 两列会把 0 显式记下来，所以这两列的空值仍然是「没采到」。

## 评估概要

**硬约束**（任一条不满足，整份产物直接判不合格、不进入质量比较）：

- **待预测的每个网点都要有一行，一个都不能缺**，网点名称原样对齐、不得重复。多写的行不报错，但同样要满足下面的取值要求。
- **选址评分必须是能解析成数值的有限数**，不得为空、不得是 inf 或 nan。
- **每一个分值都必须落在 0 到 100 的闭区间内**，只留浮点级别的容差；只要有一个值越界，整份产物就作废。

**质量评分**：成绩只看预测得准不准，没有别的成分；个别网点错得离谱，和同样多的偏差摊到很多网点身上，这两种情况我们看得一样重。

## 注意事项

- **「准不准」是按分差本身量的，不额外放大大偏差**：每个待评网点的预测分跟真实分差多少，取绝对值，再在全部待评网点上平均，这个平均分差越小越好。
