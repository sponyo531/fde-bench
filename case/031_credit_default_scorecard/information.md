# 个人信贷违约评分卡

## 业务背景

我们是消费金融公司，放款前要评估申请人的违约风险，用来决定是否授信和额度。请建一个评分模型，对新的申请人给出违约概率，把真正会违约的人尽量排到高分一侧、正常还款的人排到低分一侧，区分度越高越好，这样既能少踩坏账，也能减少好客户被误拒。

## 产物形式

结果交一份 CSV 表格。

## 评估概要

**硬约束**（任一条不满足，整份提交直接判不合格、连分都算不出来）：

- **客户号和违约概率这两列都得有**，列名要对得上；表读不出来或少一列，直接到不了打分环节。
- **待打分名单里的每个客户号都必须出现，一个不能少**，也不能重复。
- **概率那一列必须是能解析出来的有限数，且落在 0 到 1 的闭区间内**。交 300~850 的评分刻度或未经压缩的原始打分不符合要求，整份提交直接作废。

**质量评分**：只看违约客户与正常客户的风险排序能否拉开；整体排序和最有区分力的分割位置同等重要，不考核概率校准。

## 注意事项

- **只认相对排序**：整体保序变换不会改变区分度，但变换后的值仍必须是 0 到 1 内的概率。同分越多，能表达的风险顺序越粗。
- **同分按同一个风险档处理**：整体排序中同分客户取平均名次；寻找最有区分力的分割位置时，只在一个同分档全部纳入之后观察累计差异，不会按输入行顺序把同分客户拆开。
